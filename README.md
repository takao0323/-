## 📖 概要

「関口式ダイエットメンター」は、世界チャンピオン・関口貴夫さんのコーチングスタイルを参考にした、パーソナライズドダイエットサポートプログラムです。

一般的なダイエットアプリと異なり、**マニュアルに頼らず、あなたの実際の食生活データを3日間分析**し、個々に最適化されたカロリー・PFCバランス目標を自動設定します。

### 🎯 このbotの特徴

- **科学的根拠に基づく減量ペース**：月に体重の3-5%までを推奨
- **ホメオスタシスを考慮**：無茶な目標設定を防ぎ、リバウンド防止
- **関口さん風の励まし**：4900通りの組み合わせによる前向きなメッセージ
- **完全パーソナライズ**：準備期間3日間の実データから個別目標を算出

## ✨ 主な機能

### 💰 料金プラン
- **月額プラン**：月額990円

### 🎯 準備期間（3日間）によるパーソナライズ設定
実際の食生活を3日間記録し、個々の摂取カロリー・PFCバランスを自動分析。マニュアルに頼らない、あなた専用の目標を設定します。

### ⚖️ 関口からのパーソナライズ提案
プロフィール入力後、関口が最適なペースを提案：
```
「月に2.1kgずつ（ベーシックモード）、90日間で約6.3kg落としませんか？」
```

ユーザーが希望する月間減量ペースを設定でき、5%超えの無茶な目標には：
```
⚠️ それは無茶ですよ！

月に体重の5%以上減らすと、体がホメオスタシス（恒常性）で
「飢餓状態だ！」と判断して、代謝を下げてしまうんです。
```
と警告し、健康的なペースへ誘導します。

### 📊 PFCバランス管理
- **理想的な栄養バランス**：P:30% / F:20% / C:50%
- タンパク質・脂質・炭水化物の目標値を自動計算
- 日々の摂取量と目標の比較表示

### 📈 体重の自動グラフ化
毎日の体重データから自動的にグラフを生成し、進捗を視覚化します。

### 💬 関口貴夫さん風の励ましメッセージ
- 4900通りの組み合わせによる多彩なフィードバック
- 「できたこと」に焦点を当てた前向きなメッセージ
- 小さな進歩を認めて褒めるコーチングスタイル

### 🎯 目的別カスタマイズメッセージ
- ダイエット
- 増量
- 健康維持

それぞれの目的に応じた個別メッセージを提供します。

## 📱 使い方

### プログラムの流れ

1. **プラン選択**（月額990円プラン）
2. **プロフィール入力**
   - 名前、性別、年齢
   - 目的、現在の体重、目標体重
3. **関口からの提案**（ダイエット目的の場合）
   - 体重の3%/月ペースを推奨
   - ユーザーが希望する月間減量ペースを入力
   - 5%超えチェック：無茶な目標には警告
4. **準備期間（3日間）**
   - 普段通りの食事を3日間記録
   - カロリーとPFC（タンパク質・脂質・炭水化物）を入力
   - 平均値から個別の目標カロリー・PFCを自動設定
5. **日々の報告**
   - 体重、運動、食事、カロリー、PFCを入力
6. **フィードバック＆グラフ自動生成**
   - 体重変化の分析
   - 目標カロリー・PFCとの比較
   - 目的別カスタマイズメッセージ
   - 関口さん風の励まし
7. **プラン期間終了**で完了メッセージ

## 📊 科学的根拠

### 減量ペースの設定理由

このbotでは、月に体重の**3-5%**を上限としています。

#### なぜ5%が上限なのか？

月に体重の5%以上減らすと、**ホメオスタシス（恒常性）**が働き、体が「飢餓状態」と判断して以下の反応が起こります：

1. **基礎代謝の低下**：エネルギー消費を抑える
2. **脂肪蓄積モードへ移行**：少ない摂取カロリーでも脂肪として蓄える
3. **筋肉の分解**：エネルギー源として筋肉を使用
4. **リバウンドリスク増加**：元の食事に戻すと急激に体重が増える

#### 推奨ペース（3%/月）の利点

- 基礎代謝を維持
- 筋肉量を保持
- リバウンドしにくい
- 継続しやすい
- 健康的に痩せられる

### PFCバランス（P:30% F:20% C:50%）

- **P（タンパク質）30%**：筋肉維持、代謝サポート
- **F（脂質）20%**：ホルモン生成、細胞膜構成
- **C（炭水化物）50%**：エネルギー源、脳の栄養
