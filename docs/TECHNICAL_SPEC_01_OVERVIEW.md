## 1. サービス概要

### 1.1 システム名称
**関口式ダイエットメンター**
キャッチコピー: フィジークマスターズ世界一×指導歴30年×人格搭載AI

### 1.2 目的
フィジークマスターズ世界チャンピオン・関口貴夫氏の30年の指導経験をAIに搭載し、科学的根拠に基づいた減量プランと個別最適化メンタリングを提供するダイエット支援システム。

### 1.3 提供形態
- **ターミナル版**: Python CLI アプリケーション（開発・テスト用）
- **LINE Bot版**: LINE Messaging API連携（本番運用）

## 5. 主要仕様

### 5.1 料金プラン
- **月額プラン**: 990円（税込）、30日間、全機能利用可能

### 5.2 減量プラン（2種類）
- **ライトプラン**: 月間で現在体重の2%減（安全・推奨）
- **ハードプラン**: 月間で現在体重の4%減（最大効果）
- **科学的根拠**: 5%ルール（月5%超でホメオスタシス発動→リバウンド）

### 5.3 関口の指導哲学（4要素）
**「100%のトレーナー = 25%チアリーダー × 25%コメディアン × 25%バーテンダー × 25%専門家」**

| 要素 | アイコン | 役割 |
|------|----------|------|
| チアリーダー | 🎺 | 応援する（モチベーション向上） |
| コメディアン | 🎭 | 楽しませる（継続性向上） |
| バーテンダー | 🍸 | 傾聴する（共感・信頼構築） |
| 専門家 | 🎓 | 科学的根拠（納得感・効果保証） |

### 5.4 状況別最適化システム（8カテゴリー）
ユーザーの状況（体重変化、継続率、停滞日数）に応じて4要素の配分を動的調整。

例：停滞期 → 専門家40% + バーテンダー40% + チアリーダー20% + コメディアン0%

### 5.5 PFCバランス
- **P（タンパク質）**: 30%（筋肉維持）
- **F（脂質）**: 20%（ホルモンバランス）
- **C（炭水化物）**: 50%（エネルギー源）
