## 📖 概要

「関口式ダイエットメンター」は、世界チャンピオン・関口貴夫さんのコーチングスタイルを参考にした、パーソナライズドダイエットサポートプログラムです。

一般的なダイエットアプリと異なり、**マニュアルに頼らず、あなたの実際の食生活データを3日間分析**し、個々に最適化されたカロリー・PFCバランス目標を自動設定します。

### 🎯 このbotの特徴

- **関口の指導哲学を搭載**：100%のトレーナー = 25%チアリーダー（応援）×25%コメディアン（楽しませる）×25%バーテンダー（傾聴）×25%専門家（科学的根拠）
- **2つの目標設定プラン**：ライト（2%/月）とハード（4%/月）から選択
- **ホメオスタシスを考慮**：科学的に安全な範囲で目標設定、リバウンド防止
- **関口の分身を搭載**：毎日のメッセージやすべてのやり取りに4つの要素が反映
- **完全パーソナライズ**：準備期間3日間の実データから個別目標を算出

## ✨ 主な機能

### 🎯 関口の指導哲学「100%のトレーナー」

関口貴夫さんが実践する指導哲学を完全搭載：

**100%のトレーナー = 25%チアリーダー × 25%コメディアン × 25%バーテンダー × 25%専門家**

1. **🎺 チアリーダー（応援する）25%**
   - あなたの小さな前進を見逃さず、全力で応援
   - できたことに目を向け、モチベーションを維持

2. **🎭 コメディアン（楽しませる）25%**
   - 楽しく、笑顔で続けられるメッセージ
   - 真面目すぎず、リラックスしながら取り組める

3. **🍸 バーテンダー（傾聴する）25%**
   - あなたの状況を理解し、寄り添う
   - 数字だけでなく、気持ちも大切にする

4. **🎓 専門家（科学的根拠）25%**
   - ホメオスタシス、PFCバランスなど科学的根拠
   - 年齢に関係なく成長できる事実を提示

この4つの要素が、毎日のフィードバック、プラン提案、準備期間など、すべてのやり取りに反映されています。

プロフィール入力後、関口が2つのプランを提案：

**【1】ライトプラン（体重の2%/月）**

### 📈 体重の自動グラフ化
毎日の体重データから自動的にグラフを生成し、進捗を視覚化します。

## 📱 使い方

### プログラムの流れ

1. **プラン選択**（月額990円プラン）
2. **プロフィール入力**
   - 名前、性別、年齢
   - 目的、現在の体重、目標体重
3. **関口からの提案**（ダイエット目的の場合）
   - ライトプラン（2%/月）とハードプラン（4%/月）の2択を提示
   - ユーザーが好みのペースを選択
4. **準備期間（3日間）**
   - 普段通りの食事を3日間記録
   - カロリーとPFC（タンパク質・脂質・炭水化物）を入力
   - 平均値から個別の目標カロリー・PFCを自動設定
5. **日々の報告**
   - 体重、運動、食事、カロリー、PFCを入力
6. **フィードバック＆グラフ自動生成**
   - 体重変化の分析
   - 目標カロリー・PFCとの比較
   - 目的別カスタマイズメッセージ
   - 関口さん風の励まし
7. **プラン期間終了**で完了メッセージ

## 📊 科学的根拠

### 減量ペースの設定理由

このbotでは、科学的に安全な**2つのペース**を提供しています。

#### ライトプラン（2%/月）
- **最もリバウンドしにくい**：体が変化に順応しやすい
- **基礎代謝を維持**：エネルギー消費が落ちにくい
- **筋肉量を保持**：筋肉の分解を最小限に抑える
- **継続しやすい**：無理がないため、長期的に続けられる
- **初心者向け**：ダイエット初めての方に最適

#### ハードプラン（4%/月）
- **効果を実感しやすい**：月に体重の4%減で成果が見える
- **モチベーション維持**：早めの結果でやる気UP
- **安全範囲**：5%以内なので健康的
- **経験者向け**：運動習慣がある方、過去にダイエット経験がある方に最適

#### なぜ5%が上限なのか？

月に体重の5%以上減らすと、**ホメオスタシス（恒常性）**が働き、体が「飢餓状態」と判断して以下の反応が起こります：

1. **基礎代謝の低下**：エネルギー消費を抑える
2. **脂肪蓄積モードへ移行**：少ない摂取カロリーでも脂肪として蓄える
3. **筋肉の分解**：エネルギー源として筋肉を使用
4. **リバウンドリスク増加**：元の食事に戻すと急激に体重が増える

そのため、このbotでは**最大でも4%（ハードプラン）**に設定しています。

### PFCバランス（P:30% F:20% C:50%）

- **P（タンパク質）30%**：筋肉維持、代謝サポート
- **F（脂質）20%**：ホルモン生成、細胞膜構成
- **C（炭水化物）50%**：エネルギー源、脳の栄養
