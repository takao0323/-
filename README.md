# Sekiguchi Pocket Mentor Bot (Lite)

関口ポケットメンターbot（ライト版）

## 概要

関口貴夫さん風のメンタリングで、日々のボディメイクをサポートするPythonプログラムです。

## 主な機能

- 💰 **3つの料金プラン**
  - ①３日間お試しプラン／550円
  - ②３ヵ月プラン／月額990円
  - ③６ヵ月プラン／月額880円
- 🎯 **準備期間（3日間）によるパーソナライズ設定**
  - 実際の食生活を3日間記録
  - 個々の摂取カロリー・PFCバランスを自動分析
  - マニュアルに頼らない、あなた専用の目標を自動設定
- ⚖️ **体重ベースのカロリー調整モード**
  - ハードモード：体重の5%/月を目標（最大ペース）
  - マイルドモード：体重の3%/月を目標（ゆっくりペース）
  - 現在の体重から自動でカロリー削減量を計算
- 📊 **PFCバランス管理（P:30% F:20% C:50%）**
  - タンパク質・脂質・炭水化物の目標値を自動計算
  - 日々の摂取量と目標の比較表示
- 📝 日々の体重・運動・食事・栄養の記録
- 💬 関口貴夫さん風の励ましメッセージ（4900通りの組み合わせ）
- 📈 体重の自動グラフ化
- 👤 名前でパーソナライズされたメッセージ
- 🎯 目的別カスタマイズメッセージ（ダイエット・増量・健康維持）
- ⏰ プラン残り日数の表示
- 🎉 プラン完了時の特別メッセージ

## 実行方法

```bash
cd sekiguchi_bot
python3 main.py
```

## 必要なライブラリ

- matplotlib

インストール:
```bash
pip install matplotlib
```

## プログラムの流れ

1. プラン選択（3つから選択）
2. プロフィール入力（名前、性別、目的、現在の体重、目標体重、カロリー調整モード）
   - カロリー調整モード：ハード（5%/月）またはマイルド（3%/月）
3. **準備期間（3日間）** ※ダイエット目的の場合
   - 普段通りの食事を3日間記録
   - カロリーとPFC（タンパク質・脂質・炭水化物）を入力
   - 平均値と現在の体重から個別の目標カロリー・PFCを自動設定
   - 月間目標減量と1日あたりの必要カロリー削減を表示
4. 日々の報告（体重、運動、食事、カロリー、PFC）
5. フィードバック＆グラフ自動生成
   - 体重変化の分析
   - 目標カロリー・PFCとの比較
   - 目的別カスタマイズメッセージ
   - 関口さん風の励まし
6. プラン期間終了で完了メッセージ

## 生成されるファイル

- `weight_data_{名前}.csv` - 体重データ
- `weight_graph_{名前}.png` - 体重グラフ
- `profile_{名前}.json` - プロフィール情報
